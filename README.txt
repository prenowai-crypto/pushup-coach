Push-Up Coach V3.2 Audio

Questa versione mantiene il motore di conteggio della V3 e sostituisce speechSynthesis con normali file MP3.

UPLOAD SU GITHUB
1. Sostituisci index.html con quello di questa cartella.
2. Carica anche l'intera cartella audio/ con tutti i file .mp3.
3. Mantieni la struttura: index.html e cartella audio allo stesso livello.
4. Fai Commit changes e attendi GitHub Pages.
5. Ricarica la pagina forzatamente.

TEST
- Premi AVVIA: dovresti sentire "Pronto. Vai."
- Completa una rep: sentirai il numero.
- Il pulsante VOCE attiva/disattiva i clip.

Nota: i clip inclusi sono sintetici e volutamente semplici; possono essere sostituiti in futuro con registrazioni naturali mantenendo gli stessi nomi file.
