PUSH-UP COACH V2 — iPhone/Safari

1. Pubblica questa cartella su un host HTTPS (GitHub Pages, Netlify, Cloudflare Pages, ecc.).
2. Apri l'URL HTTPS con Safari su iPhone.
3. Premi AVVIA e consenti la fotocamera.
4. Posiziona l'iPhone lateralmente, abbastanza lontano da vedere tutto il corpo.
5. Parti con le braccia distese. Una rep valida deve attraversare UP -> DOWN -> BOTTOM -> ASCESA -> UP.
6. CAMERA alterna posteriore/frontale. RESET azzera la serie.

Nota: questa è una build di test, non un dispositivo medico né una validazione biomeccanica.
